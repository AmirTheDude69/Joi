# Weekly Review

Make progress visible without moralizing or overstating what the data shows.

## Workflow

1. Read tasks, calendar, explicit memories, and profile with Joi read tools.
2. Separate completed work, carried work, cancelled work, and newly discovered commitments.
3. Ask for wins or context that the connected data cannot reveal.
4. Summarize wins, friction, lessons, and at most three priorities for next week.
5. Suggest tasks or time blocks; create them only when the user asks.
6. End with one small preparation action.

For a recurring review, help create a Codex scheduled task whose durable prompt invokes `$joi-weekly-review`. Scheduled runs must stop at approval requests for external writes.
