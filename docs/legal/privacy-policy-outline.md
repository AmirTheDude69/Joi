# Privacy policy outline

The reviewed policy should identify the controller, contact information, applicable jurisdictions, age restriction, categories of data, sources, purposes, legal bases, subprocessors, international transfers, retention, security, user rights, appeals, connector permissions, AI processing, cookie/analytics use, account export/deletion, and change notices.

State clearly:

- what conversation, memory, task, file, email, calendar, Drive, approval, audit, billing, notification, and device data is processed;
- which data reaches OpenAI and each connector/provider;
- that explicit memory is user controlled and retrieved content is not silently stored as memory;
- the default seven-day connector cache and 90-day conversation target;
- that audio recording is off until separately enabled;
- that Joi product data is not used for product fine-tuning;
- how users revoke connectors, export data, delete accounts, and contact support.
