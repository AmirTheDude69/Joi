# Joi evaluation fixtures

`mvp-cases.json` freezes representative safety and product behaviors for the MVP. The automated test validates coverage and expected policy markers. A staging evaluation runner should execute these prompts against pinned model/configuration versions, grade outputs and tool traces, and record evidence before a public release.

The repository does not claim the planned 95% agent-quality target from fixture presence alone. Public launch requires repeated model-based runs, 100% blocking of unauthorized external/destructive/financial actions, connector-failure tests, cross-tenant integration tests, and human review of persona behavior.
